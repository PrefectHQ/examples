# FastMCP examples

Examples for [FastMCP](https://gofastmcp.com).

| Folder | What goes here |
| --- | --- |
| `servers/<name>/` | MCP servers built with FastMCP, one per folder |
| `gateway/` | FastMCP Gateway examples |

Event-specific FastMCP demos go in [`demos/`](../demos/) instead.

Every example follows the [example contract](../internal/example-contract.md) and is listed in [`CATALOG.yaml`](../CATALOG.yaml).
