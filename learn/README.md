# Learning paths

> The Prefect Accelerated Learning curriculum in `pal/` moves here in phase 2. Dagster University course projects follow later.

Every example follows the [example contract](../internal/example-contract.md) and is listed in [`CATALOG.yaml`](../CATALOG.yaml).
