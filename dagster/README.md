# Dagster examples

Examples for [Dagster](https://docs.dagster.io) and Dagster+.

| Folder | What goes here |
| --- | --- |
| `projects/<name>/` | Complete showcase projects, each a self-contained Dagster project |
| `integrations/<tool>/` | Dagster with one other tool |

Snippets that exist only to test a page in the Dagster docs (`docs_snippets`) stay in the Dagster repo next to that page.

Every example follows the [example contract](../internal/example-contract.md) and is listed in [`CATALOG.yaml`](../CATALOG.yaml).
